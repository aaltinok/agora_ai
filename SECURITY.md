# Güvenlik Politikası

## Açık bildirme
Güvenlik açığını **herkese açık issue olarak açmayın**. GitHub'da *Security → Report a vulnerability* (özel danışma) kullanın. 5 iş günü içinde yanıt vermeyi hedefleriz.

## Desteklenen sürümler
Yalnızca en son sürüm (`CHANGELOG.md`).

## Kapsam ve ilkeler
Ayrıntı: `docs/security.md`. Özet: sırlar repoya girmez, kullanıcı metni loglanmaz, oturum verisi yalnızca bellekte tutulur, kriz ifadeleri persona yerine destek mesajıyla karşılanır, uzak LLM için https zorunludur.
